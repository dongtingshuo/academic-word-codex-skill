# Changelog / 更新记录

This project follows [Semantic Versioning](https://semver.org/) for published releases. / 本项目的正式发布遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.0] - 2026-07-26

### 中文

- 首次稳定发布中文论文、学位论文与课程报告 Word 完稿 Skill。
- 提供通用课程报告和明确选择的华科论文两种文档外壳。
- 支持从材料起草与保留原文重排，使用 Word 原生样式、编号、字段、题注、交叉引用、OMML 公式和分节页码。
- 提供净化后的 Word 母版、结构验证器、真实 Word 导出截图与中英文文档。
- 补充隐私、安全、贡献、Issue/PR 模板、依赖更新和本地文档链接检查。
- 明确原创代码 MIT 许可与净化模板资产的来源和许可边界。

### English

- First stable release of the Word-finishing skill for Chinese papers, theses, and course reports.
- Includes a generic course-report shell and an explicitly selected HUST thesis shell.
- Supports evidence-based drafting and content-preserving reformatting with native Word styles, numbering, fields, captions, cross-references, OMML equations, and sectioned page numbering.
- Provides sanitized Word masters, structural validation, genuine Word-exported screenshots, and bilingual documentation.
- Adds privacy, security, contribution, issue and pull-request templates, dependency updates, and local documentation-link validation.
- Clarifies the boundary between the MIT-licensed original code and the provenance of sanitized template assets.
